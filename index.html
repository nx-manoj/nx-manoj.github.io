About

I care more about the cleaning than the model

Most of the value in a data project is decided before any model is fitted. In the Bengaluru study, one row in seven was unusable — duplicates, impossible floor areas, area stored as text across six units. In the air-quality study, the monitoring network grew twelve-fold, so a national average would have measured coverage rather than air. Both of those are data decisions, and both change the answer.

So I work in a fixed order: audit the raw file, make every exclusion explicit and counted, model against a naive baseline, then report the failure modes. A model that under-predicts above ₹1.5 crore is more useful described than hidden.

Each project ships as a reproducible notebook plus a written report and a deck — the same finding in three formats, all generated from one source so no number drifts between them.
